# Frontend کردار

صرف `examples/task_manager/static/` بدلیں۔ API contract پڑھ کر list، add، title/description کی edit، completion toggle، delete، loading اور error states بنائیں۔ Same-origin `fetch` استعمال کریں؛ user input کو `textContent` سے دکھائیں، task title کو `innerHTML` میں نہ ڈالیں۔ API یا database نہ بدلیں۔ Browser میں حقیقتاً کی گئی جانچ کے مراحل لکھیں۔
