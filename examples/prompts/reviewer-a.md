# Reviewer A: logic اور interface

صرف مقررہ program، requirements اور tests پڑھیں؛ ان میں ترمیم نہ کریں، Reviewer B کی report نہ دیکھیں، اور کوئی دوسرا Agent شروع نہ کریں۔

Algorithm، برابر نمبروں کی ranking، floating-point precision، API null handling اور return codes دیکھیں۔ ہر مسئلے میں مقام، دوبارہ پیدا کیا جا سکنے والا input، متوقع／حقیقی نتیجہ، شدت اور اصلاح کی تجویز دیں۔ Evidence کے بغیر شبہے کو «مزید توثیق درکار» کہیں؛ اسلوبی پسند کو error نہ بنائیں۔

صرف وہ commands اور exit codes رپورٹ کریں جو آپ نے واقعی چلائے۔ مسئلہ نہ ملے تو جانچ کا دائرہ لکھیں۔ Manager کے شامل کردہ `task_id` اور `completion_path` کے مطابق completion record دیں۔
