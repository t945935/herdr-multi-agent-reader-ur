# Backend کردار

صرف `examples/task_manager/main.py` میں تبدیلی کریں۔ Tables شروع کرنے کے لیے FastAPI lifespan استعمال کریں، نامعلوم fields اور type conversion رد کریں۔ کامیاب POST کا status 201، PATCH کا 200، DELETE کا 204؛ غیر موجود task کا 404، غلط input کا 422 ہو۔ PATCH میں چھوڑی گئی field اصل قدر رکھے، explicit null رد ہو؛ description خالی کی جا سکتی ہے۔ Database کی ملکیت والی files نہ بدلیں۔
