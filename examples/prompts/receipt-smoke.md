# مقامی implementation کی قبولیت: صرف پڑھنے کی جانچ

`examples/calculator.py` پڑھیں اور چار public functions کے نام اور divide-by-zero exception کی تصدیق کریں۔ کوئی program، test یا chapter file نہ بدلیں، دوسرے Agent کو call نہ کریں۔

Manager کے مقررہ `completion_path` میں completion JSON لکھیں؛ `summary` میں وہ functions اور exception بتائیں جو حقیقتاً دیکھے، `artifacts` میں `examples/calculator.py` کا absolute path دیں۔ صرف یہی ایک completion record لکھنا ہے۔ File نہ پڑھ سکیں تو `blocked` بتائیں؛ نتیجہ ایجاد نہ کریں۔
